Module 01

The Dual Core System

Para dominar el Pasado Simple, debes entender que existen dos carriles paralelos que NUNCA se cruzan. O estás describiendo un estado, o estás describiendo una acción.

The State

Was / Were

Existencia, ubicación, descripción. Sin movimiento físico.

The Action

Verbs + ED / Did

Eventos concretos que empezaron y terminaron.

Fatal Error Warning

Nunca mezcles los carriles.
Incorrecto: "Did you were happy?"
Correcto: "Were you happy?"

Core A

The State: Was / Were

Aquí NO usamos auxiliares. El verbo To Be es el rey y se manda solo. Se usa para descripciones y ubicaciones en el pasado.

Affirmative Formula

Subject
WAS / WERE
Adjective / Place
AudioExampleContext
I was tired. Feeling (Estado)
They were at the park. Location (Ubicación)

The Action: Regular Verbs

Para narrar historias y eventos, usamos verbos de acción. Si el verbo es regular, la regla de oro es agregar -ED.

Subject
Verb + ED
Complement

Work → Worked

Standard Rule

Live → Lived

Ends in E (+d)

Study → Studied

Y becomes I (+ed)

Spelling Rules

No siempre es solo poner "-ed". Aquí están las dos excepciones críticas para escribir correctamente.

Y → IED

Si termina en Consonante + Y, elimina la Y.

Cry → Cried

Try → Tried

Double

Verbos cortos (CVC) duplican la última letra.

Stop → Stopped

Plan → Planned

The -ED Sounds

La terminación -ED tiene 3 sonidos diferentes. No todo suena como "ed". Haz clic para escuchar la diferencia real.

/t/

Sonido Seco (T)

Para verbos con sonido final de aire (K, P, S, SH, F).

Work-t • Kiss-t
/d/

Vibrante (D)

Para verbos que vibran (L, N, R, V, Vocales).

Play-d • Call-d
/ɪd/

Sílaba Extra (ID)

SOLO si el verbo termina en T o D.

Want-ed • Need-ed

The "Did" Trap

Aquí falla el 90% de los estudiantes. En oraciones negativas y preguntas, aparece el auxiliar DID.

Toxicidad Gramatical

Si usas Did o Didn't, el verbo principal pierde su poder. Debe regresar a su FORMA BASE (Sin -ed).

Negative Structure

Subject
DIDN'T
Base Verb

She didn't work yesterday.

Base Verb
